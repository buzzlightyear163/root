How the root is dated

  1. Every contract with the name

    ROOT searches DexScreener and Jupiter for the name and the ticker. That covers coins still on the pump.fun curve and fresh mints that haven't opened a pool yet.

  2. Every pool it ever opened

    For each contract it takes the earliest moment either source saw it: the mint itself or its first pool. That's the contract's birth.

  3. Oldest that ran wins

    Sorted by birth, the first contract that actually got holders is the root. Older ones that used the name and never ran are listed, not counted. Everything after the root is a copy, however big its market cap looks.

  4. Same picture gets flagged

    Each copy's picture is compared with the root's, pixel by pixel at thumbnail size. A near-identical picture marks it as a straight clone.

Only Solana counts. Contracts with the same name on other chains are listed and never bought. Data comes from the public DexScreener and Jupiter APIs, no keys.
